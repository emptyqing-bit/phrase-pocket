# 随手收 · Phrase Pocket

刷 TikTok、哔哩哔哩和抖音网页版时，记下想学的英文表达、种草信息或随手备忘。Chrome / Edge 扩展可以独立使用；连接可选的 Windows 组件后，桌面角落也能轮换显示收藏。

| 只装浏览器扩展 | 加装 Windows 组件 |
| --- | --- |
| 视频旁记录单词和备忘 | 桌面常驻卡片，可调轮换间隔 |
| 字幕可读时预填，也能直接输入 | 可选只显示单词、只显示备忘或两种都显示 |
| 收藏、编辑、离线查常用表达 | 随包内置 6 万条英汉词条，也可导入完整 ECDICT |

## 安装浏览器扩展

1. 解压 **PhrasePocket-Extension**，或下载源码后使用其中的 **extension** 文件夹。
2. 打开 **chrome://extensions** 或 **edge://extensions**，开启「开发者模式」并选择「加载已解压的扩展程序」。选中直接包含 **manifest.json** 的文件夹。
3. 打开或刷新支持的视频网站，点右下角「随手收」，选择「记单词」或「记备忘」。输入后按回车保存。也可以按 **Alt+Shift+S** 打开记录框。

已有插件可先在「我的收藏 → 备份与导出」备份，再用新版文件覆盖原扩展目录。在扩展管理页点击「重新加载」，确认新网站的访问权限，然后刷新视频网页。快捷键未生效时，可在 **chrome://extensions/shortcuts** 或 **edge://extensions/shortcuts** 检查分配。

## 在视频页记录

先选中网页上可复制的英文，再按快捷键，可以把选中的文字带入记录框。记录框里的「取当前字幕」会尝试读取当前播放器的英文文本，可编辑后再保存。

| 网站 | 记录与取字幕 |
| --- | --- |
| TikTok 网页版 | 支持手动输入、选中文字和尝试读取播放器英文字幕。 |
| 哔哩哔哩网页版 | 支持手动输入、选中文字和尝试读取当前播放器显示的英文 CC 字幕。先在播放器中打开英文字幕。 |
| 抖音网页版 | 支持手动输入和选中文字。若播放器提供可读的英文字幕轨道，也可尝试预填。 |

只有画面里印着字幕，或按钮提示「当前没有可读取的英文字幕」时，直接输入即可。三个网站的记录都出现在同一个「我的收藏」中。点击浏览器工具栏的随手收图标即可打开收藏页并编辑释义。

收藏页支持搜索全部单词、释义和备忘。「备份与导出」可以下载完整 JSON 备份，或把带释义的单词导成 Anki 可导入的 TSV。合并导入会按类型和内容去重。移除扩展前可以先导出备份。单词旁的「朗读」调用系统安装的本地英语语音。

## 可选：连接 Windows 桌面卡片

1. 完整解压 **PhrasePocket-Windows** 到准备长期保留的文件夹，双击 **Install.cmd**。支持 Windows 10/11，无需管理员权限。
2. 在扩展的「我的收藏」点击「连接 Windows 卡片」。已有浏览器收藏会复制到桌面收藏，之后新记录直接保存到桌面收藏。切回浏览器模式时会将当前桌面收藏复制回来。
3. 在桌面卡片右上角「⋯」切换显示类型、轮换频率和释义设置。默认每 5 分钟换一条。拖动标题可挪位置，点 × 收起后双击系统托盘图标可展开。

插件独立使用时，内置小词表能查 **awkward**、**count me in**、**I’m down** 等常用表达。Windows 安装包另含从 ECDICT 选出的 6 万条英汉词条，连接桌面后即可离线查询。已有的无释义词可在收藏页点「查释义」。

需要更多词条时，可从 [ECDICT 发布页](https://github.com/skywind3000/ECDICT/releases/tag/1.0.28)下载 **ecdict-sqlite-28.zip**，解压后在桌面「⋯ → 导入 ECDICT 词典」选择数据库。随包词库使用 [ECDICT MIT 许可](https://github.com/skywind3000/ECDICT/blob/39cfb9672c0906b63569e0453c2e6abfb9ab182a/LICENSE)。

如果已安装 [Ollama](https://docs.ollama.com/) 并下载了本地模型，可在「⋯ → 设置本机模型」填写模型名。遇到词典未收录的表达，先保存再补释义。留空即关闭。

## 收藏存在哪里

浏览器模式保存在当前浏览器配置；桌面模式保存在 **%LOCALAPPDATA%\PhrasePocket**。应用不记录浏览历史、视频链接或播放时间点。主动取到的一句字幕只用于当次查释义，不入库；备忘不送去翻译。

浏览器模式下，移除扩展会清除该浏览器的扩展数据。移动桌面安装目录后要重新运行 **Install.cmd**。**Uninstall.cmd** 只移除本副本的浏览器连接，保留桌面收藏。

## 从源码构建

- 浏览器扩展：直接加载 **extension/**。使用 Node.js 22.13+ 运行 **node scripts/browser-smoke.mjs**。
- Windows 组件：使用 Node.js 22.13+ 运行 **scripts/build.ps1**。首次构建会下载固定版本的 ECDICT 源数据，生成 **build/PhrasePocket.exe** 和 **build/ecdict-bundled.db**。不需要另装 .NET SDK。
- 一次打包插件、Windows 版和源码：运行 **scripts/package.ps1**。运行 **node scripts/smoke.mjs --ui** 验证本机通信、词典导入和桌面窗口初始化。
